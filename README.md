# SIERA Portal — Region 5 Erajaya Digital

Smart Integrated Erajaya Retail Analytics — unified internal dashboard untuk seluruh divisi Region 5.

**URL:** si-era.netlify.app

## Modul

| Divisi | Modul | Status |
|---|---|---|
| OPERATIONS | ERA-SALES | Active |
| RCM | ERA-ANALYTICS + ERA-PROMO | Active / Planned |
| RMO | ERA-VIS + SIGNTAX-ERA | Active |
| RCD | ERA-SITE | Coming Soon |

## Setup

1. Clone repo ini
2. Salin `config.example.js` → `config.js`
3. Isi semua nilai di `config.js`
4. Buka `index.html` di browser

## Deploy

Drag folder project ke [Netlify Drop](https://app.netlify.com/drop) atau connect repo untuk auto-deploy.

## Tech Stack

Vanilla JS · Google Sheets API · Fonnte API · Claude API · Netlify
